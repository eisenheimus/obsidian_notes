
**Таблицы (главные 3):**

- **`filter`** (по умолчанию) — разрешать/запрещать трафик (основная работа).    
- **`nat`** — менять адреса (Source/Destination NAT для маршрутизации).    
- **`mangle`** — менять TTL, TOS (используется редко, для нестандартной маршрутизации).


**Цепочки в таблице `filter` (самые важные):**

- **INPUT** — пакеты, **пришедшие** на сам сервер (к вашему приложению).    
- **OUTPUT** — пакеты, **идущие от** самого сервера наружу.    
- **FORWARD** — транзитные пакеты (сервер выступает как роутер, пробрасывает трафик дальше).

Есть два подхода к безопасности:

- **`ACCEPT`** (разрешительный): «Разрешаю всё, запрещаю конкретное» — **небезопасно*    
- **`DROP`** (запретительный): «Запрещаю всё, разрешаю конкретное» — **золотой стандарт**.

Пример 
```bash
#Перевод: _"Добавить (-A) в цепочку INPUT правило: протокол TCP, порт назначения 22, с IP-сети 192.168.1.0/24, прыгнуть (-j) в цель ACCEPT (разрешить)".

iptables -A INPUT -p tcp --dport 22 -s 192.168.1.0/24 -j ACCEPT
```

Ключи:
- `-p` — протокол (tcp, udp, icmp).    
- `--dport` / `--sport` — порт **назначения** / **источника**.    
- `-s` / `-d` — IP-адрес **источника** / **назначения**.    
- `-i` / `-o` — входящий / исходящий **интерфейс** (например, `-i eth0`).
-  `-A` (append — добавить в конец) часто спрашивают:
- **`-I`** (Insert) — вставить **первым** номером (важно для правил DROP).    
- **`-D`** (Delete) — удалить правило (нужно указать его номер или точную строку).    
- **`-L -v -n`** — посмотреть правила (список).    
    - `-n` — не резолвить IP в имена (ускоряет вывод).        
    - `--line-numbers` — показать номера строк, чтобы удалять по номеру.

```bash
# Часто используемое
iptables -L -n -v                 # Посмотреть все правила в filter
iptables -t nat -L -n -v          # Посмотреть NAT
iptables -D INPUT 3               # Удалить правило №3 в цепочке INPUT
iptables -F                       # Очистить ВСЕ правила (флаш) в таблице filter
```

### Шпаргалка для быстрого повторения:

| Действие                                        | Команда                                                      |
| ----------------------------------------------- | ------------------------------------------------------------ |
| Разрешить SSH                                   | `iptables -A INPUT -p tcp --dport 22 -j ACCEPT`              |
| Заблокировать IP-хулигана                       | `iptables -A INPUT -s 5.5.5.5 -j DROP`                       |
| Открыть диапазон портов                         | `iptables -A INPUT -p tcp --dport 3000:4000 -j ACCEPT`       |
| Запретить пинг (ICMP)                           | `iptables -A INPUT -p icmp --icmp-type echo-request -j DROP` |
| Сделать NAT (маскарадинг) для выхода в интернет | `iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE`       |
