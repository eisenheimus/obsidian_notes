
**Таблицы (главные 3):**

- **`filter`** (по умолчанию) — разрешать/запрещать трафик (основная работа).    
- **`nat`** — менять адреса (Source/Destination NAT для маршрутизации).    
- **`mangle`** — менять TTL, TOS (используется редко, для нестандартной маршрутизации).


**Цепочки в таблице `filter` (самые важные):**

- **INPUT** — пакеты, **пришедшие** на сам сервер (к вашему приложению).    
- **OUTPUT** — пакеты, **идущие от** самого сервера наружу.    
- **FORWARD** — транзитные пакеты (сервер выступает как роутер, пробрасывает трафик дальше).

Есть два подхода к безопасности:

- **`ACCEPT`** (разрешительный): «Разрешаю всё, запрещаю конкретное» — **небезопасно*    
- **`DROP`** (запретительный): «Запрещаю всё, разрешаю конкретное» — **золотой стандарт**.

Пример 
```bash
#Перевод: _"Добавить (-A) в цепочку INPUT правило: протокол TCP, порт назначения 22, с IP-сети 192.168.1.0/24, прыгнуть (-j) в цель ACCEPT (разрешить)".

iptables -A INPUT -p tcp --dport 22 -s 192.168.1.0/24 -j ACCEPT

iptables -P INPUT DROP   # Закрыли всё
```

Ключи:
- `-p` — протокол (tcp, udp, icmp).    
- `--dport` / `--sport` — порт **назначения** / **источника**.    
- `-s` / `-d` — IP-адрес **источника** / **назначения**.    
- `-i` / `-o` — входящий / исходящий **интерфейс** (например, `-i eth0`).
-  `-A` (append — добавить в конец) часто спрашивают:
- **`-I`** (Insert) — вставить **первым** номером (важно для правил DROP).    
- **`-D`** (Delete) — удалить правило (нужно указать его номер или точную строку).    
- **`-L -v -n`** — посмотреть правила (список).    
    - `-n` — не резолвить IP в имена (ускоряет вывод).        
    - `--line-numbers` — показать номера строк, чтобы удалять по номеру.

|**`-A`** (Append)|Добавляет **правило**|В конец цепочки|Проверяет конкретные условия (порт, IP, протокол)|
|**`-P`** (Policy)|Устанавливает **политику**|На всю цепочку целиком|Срабатывает, если ни одно правило не подошло|

|   |   |   |
|---|---|---|
|**`-P`**|**Policy**|Меняет политику по умолчанию для цепочки|
|`-A`|Append|Добавляет правило в конец цепочки|
|`-I`|Insert|Вставляет правило в начало (или на указанную позицию)|
|`-D`|Delete|Удаляет правило|
|`-L`|List|Показывает список правил|
|`-F`|Flush|Очищает все правила (но НЕ трогает политику!)|


```bash
# Часто используемое
iptables -L -n -v                 # Посмотреть все правила в filter
iptables -t nat -L -n -v          # Посмотреть NAT
iptables -D INPUT 3               # Удалить правило №3 в цепочке INPUT
iptables -F                       # Очистить ВСЕ правила (флаш) в таблице filter
```

### Шпаргалка для быстрого повторения:

| Действие                                        | Команда                                                      |
| ----------------------------------------------- | ------------------------------------------------------------ |
| Разрешить SSH                                   | `iptables -A INPUT -p tcp --dport 22 -j ACCEPT`              |
| Заблокировать IP-хулигана                       | `iptables -A INPUT -s 5.5.5.5 -j DROP`                       |
| Открыть диапазон портов                         | `iptables -A INPUT -p tcp --dport 3000:4000 -j ACCEPT`       |
| Запретить пинг (ICMP)                           | `iptables -A INPUT -p icmp --icmp-type echo-request -j DROP` |
| Сделать NAT (маскарадинг) для выхода в интернет | `iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE`       |




## 1. Базовые понятия (с чего начать ответ)

**iptables** — интерфейс к Netfilter в ядре Linux.  
Пакет проходит цепочки (`INPUT`, `OUTPUT`, `FORWARD`) в таблицах (`filter`, `nat`, `mangle`...).  
**Первое совпадение (match) — правило срабатывает**, дальше не идёт (если не `-j ACCEPT`).

## 2. Таблицы (главные 3)

- **filter** (по умолчанию) — разрешить/запретить. Цепочки: INPUT, OUTPUT, FORWARD.
    
- **nat** — трансляция адресов (SNAT/DNAT). Цепочки: PREROUTING, POSTROUTING, OUTPUT.
    
- **mangle** — изменение TTL, TOS, маркировка. Цепочки: PREROUTING, POSTROUTING, INPUT, OUTPUT, FORWARD.
    

**Важно:** В `nat` нельзя фильтровать, только изменять заголовки.

## 3. Цепочки и порядок обхода

- **Входящий (к серверу)**: PREROUTING (nat/mangle) → INPUT (filter).
    
- **Исходящий (от сервера)**: OUTPUT (filter/mangle/nat) → POSTROUTING (nat/mangle).
    
- **Транзитный (роутер)**: PREROUTING → FORWARD (filter) → POSTROUTING.
    

## 4. Основные команды (запомни флаги)

- `-A` (append) — добавить в конец.
    
- `-I` (insert) — вставить наверх (по умолчанию 1).
    
- `-D` — удалить.
    
- `-L` — список правил (`-v` подробно, `-n` без DNS).
    
- `-F` — очистить цепочку.
    
- `-P` — политика по умолчанию (DROP/ACCEPT).
    

## 5. Критические параметры (match)

- `-s` / `-d` — source/dest IP.
    
- `--dport` — порт назначения (только после `-p tcp/udp`).
    
- `-i` / `-o` — входящий/исходящий интерфейс.
    
- `-m state --state` — NEW, ESTABLISHED, RELATED (обязательно помни!).
    

## 6. Типовые примеры (отвечай сразу)

- **Открыть SSH**:  
    `iptables -A INPUT -p tcp --dport 22 -j ACCEPT`
    
- **Разрешить установленные соединения**:  
    `iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT`
    
- **SNAT (маскарад)**:  
    `iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE`
    
- **DNAT (проброс порта)**:  
    `iptables -t nat -A PREROUTING -p tcp --dport 8080 -j DNAT --to-dest 192.168.1.10:80`
