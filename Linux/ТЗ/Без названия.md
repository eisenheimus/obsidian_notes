
  
## Решение задания 1

 **Udev** — определяет подключение USB-накопителя с нужным idVendor/idProduct и создаёт (или не создаёт) соответствующий объект в /dev/disk/by-uuid/ или устанавливает свойство ENV{UDISKS_AUTO}, влияющее на udisks. 
 
**Polkit** — управляет правилами для udisks2 (стандартный механизм монтирования в современных Linux с GNOME/KDE/XFCE).

**Группы** — GroupUSBNoPassword, GroupUSBPassword.

**Доступ к ttyACM** — через udev и проверку ID_SEAT (только физическая консоль).


 #### Bash скрипт
```bash
bash

#!/bin/bash
# setup_usb_mount_policy.sh
# Настройка политик монтирования USB и доступа к ttyACM для Debian Trixie
if [ "$EUID" -ne 0 ]; then
    echo "Нужны права root" >&2
    exit 1
fi
# Создаём группы
groupadd -f GroupUSBNoPassword
groupadd -f GroupUSBPassword
# Ставим пакеты
apt update
apt install -y udisks2 policykit-1
# udev правило для нужной флешки (SanDisk 0x0781:0x5583)
cat > /etc/udev/rules.d/99-usb-mount-polkit.rules <<EOF

ACTION=="add", SUBSYSTEM=="block", ENV{ID_BUS}=="usb", \
ENV{ID_VENDOR_ID}=="0781", ENV{ID_MODEL_ID}=="5583", \
ENV{ID_FS_USAGE}=="filesystem", \
TAG+="uaccess"

EOF
# Polkit правило
cat > /etc/polkit-1/rules.d/99-usb-mount.rules <<EOF
polkit.addRule(function(action, subject) {
    if (action.id != "org.freedesktop.udisks2.filesystem-mount" &&
        action.id != "org.freedesktop.udisks2.filesystem-mount-system") {
        return polkit.Result.NOT_HANDLED;
    }
    
    var vendor = action.lookup("id_vendor");
    var product = action.lookup("id_product");
    
    // Наша флешка
    if (vendor == "0781" && product == "5583") {
        if (subject.isInGroup("GroupUSBNoPassword"))
            return polkit.Result.YES;
        if (subject.isInGroup("GroupUSBPassword"))
            return polkit.Result.AUTH_ADMIN_KEEP;
        return polkit.Result.NO;
    }
    
    // Остальные USB - запрет
    if (action.lookup("bus") == "usb")
        return polkit.Result.NO;
    
    return polkit.Result.NOT_HANDLED;
});
EOF
# ttyACM - только локальная консоль
cat > /etc/udev/rules.d/98-ttyacm-local.rules <<EOF
SUBSYSTEM=="tty", KERNEL=="ttyACM[0-9]*", \
TAG+="uaccess", OWNER="root", MODE="0600"
EOF
# Применяем
udevadm control --reload-rules
udevadm trigger
systemctl restart polkit
echo "Готово."
echo "Добавь пользователей в группы:"
echo "  usermod -aG GroupUSBNoPassword пользователь"
echo "  usermod -aG GroupUSBPassword пользователь"
```

## Решение задания 2

#### Решение

**Механизм 1: systemd timer** — создаётся пользовательский systemd-сервис и таймер, который запускает проверку существования файла `неудаляемый_1.txt` каждые 2 секунды. Если файл отсутствует и нет флага отключения, сервис восстанавливает его.

**Механизм 2: polling loop** — запускается фоновый процесс, который каждые 3 секунды проверяет существование файла `неудаляемый_2.txt` и восстанавливает его при необходимости.

**Механизм 3: inotify** — используется утилита `inotifywait`, которая отслеживает событие удаления файла `неудаляемый_3.txt` и мгновенно восстанавливает его.

**Флаг отключения** — все механизмы проверяют наличие файла `/tmp/quiz_disabled`. При его создании процессы завершают работу на следующей итерации.

**Рабочий стол** — путь определяется автоматически: `$HOME/Рабочий стол` (русская локаль) или `$HOME/Desktop` (английская).

```bash
#!/bin/bash
# quiz_setup.sh - настройка неудаляемых файлов

DESKTOP="$HOME/Рабочий стол"
[ ! -d "$DESKTOP" ] && DESKTOP="$HOME/Desktop"

# Очистка старых процессов
pkill -f "polling_watchdog" 2>/dev/null
pkill -f "inotifywait" 2>/dev/null
systemctl --user stop watchdog_file1.timer 2>/dev/null

# Создание файлов
echo "Файл 1 (systemd timer)" > "$DESKTOP/неудаляемый_1.txt"
echo "Файл 2 (polling loop)" > "$DESKTOP/неудаляемый_2.txt"
echo "Файл 3 (inotify)" > "$DESKTOP/неудаляемый_3.txt"

# Механизм 1: systemd timer (каждые 2 секунды)
mkdir -p ~/.config/systemd/user
cat > ~/.config/systemd/user/watchdog_file1.service <<'EOF'
[Service]
Type=oneshot
ExecStart=/bin/bash -c 'F="%h/Рабочий стол/неудаляемый_1.txt"; [ ! -d "%h/Рабочий стол" ] && F="%h/Desktop/неудаляемый_1.txt"; [ ! -f "$F" ] && [ ! -f /tmp/quiz_disabled ] && echo "Файл 1 (systemd timer)" > "$F"'
EOF

cat > ~/.config/systemd/user/watchdog_file1.timer <<EOF
[Unit]
Description=Watchdog for file1
[Timer]
OnBootSec=2s
OnUnitActiveSec=2s
[Install]
WantedBy=timers.target
EOF

systemctl --user daemon-reload
systemctl --user enable --now watchdog_file1.timer

# Механизм 2: polling loop (каждые 3 секунды)
(
    while true; do
        if [ ! -f "$DESKTOP/неудаляемый_2.txt" ] && [ ! -f /tmp/quiz_disabled ]; then
            echo "Файл 2 (polling loop)" > "$DESKTOP/неудаляемый_2.txt"
        fi
        sleep 3
    done
) &

# Механизм 3: inotify (мгновенное восстановление)
if ! command -v inotifywait >/dev/null 2>&1; then
    echo "Установите inotify-tools: sudo apt install -y inotify-tools"
    exit 1
fi

(
    while true; do
        inotifywait -e delete "$DESKTOP" --format '%f' 2>/dev/null | while read file; do
            if [ "$file" = "неудаляемый_3.txt" ] && [ ! -f /tmp/quiz_disabled ]; then
                echo "Файл 3 (inotify)" > "$DESKTOP/неудаляемый_3.txt"
            fi
        done
    done
) &

echo "Готово. Файлы защищены."
echo "Отключение: touch /tmp/quiz_disabled"
echo "Остановка: systemctl --user stop watchdog_file1.timer && pkill -f 'polling' && pkill -f inotifywait"
```

#### Проверка
```bash
# Проверка создания файлов
ls -la "$HOME/Рабочий стол/неудаляемый_"* 2>/dev/null || ls -la "$HOME/Desktop/неудаляемый_"*

# Удаление первого файла (восстановление через 2 секунды)
rm "$HOME/Рабочий стол/неудаляемый_1.txt" 2>/dev/null || rm "$HOME/Desktop/неудаляемый_1.txt"
sleep 3
ls -la "$HOME/Рабочий стол/неудаляемый_1.txt" 2>/dev/null || ls -la "$HOME/Desktop/неудаляемый_1.txt"

# Удаление всех файлов и наблюдение за восстановлением
rm "$HOME/Рабочий стол/неудаляемый_"*.txt 2>/dev/null || rm "$HOME/Desktop/неудаляемый_"*.txt
watch -n 1 'ls -la "$HOME/Рабочий стол/неудаляемый_"* 2>/dev/null || ls -la "$HOME/Desktop/неудаляемый_"* 2>/dev/null'

# Отключение всех механизмов
touch /tmp/quiz_disabled
systemctl --user stop watchdog_file1.timer
pkill -f "while true" 2>/dev/null
pkill -f inotifywait 2>/dev/null
```
