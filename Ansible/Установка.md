
##### Установка WSL и настройка дистрибутива
```powershell
# Устновить WSL
wsl --install
```

```powershell
# Проверьте установленные дистрибутивы
wsl --list --verbose
```

```powershell
#  Запустите нужный дистрибутив
wsl -d Ubuntu
```

```powershell
# Сделайте Ubuntu дистрибутивом по умолчанию
wsl --set-default Ubuntu
```

#### Установка python3
```bash
# обнвление индексов
sudo apt update

#обновление пакетов
sudo apt upgrade

# установка python и pip и pipx
sudo apt install python3 python3-pip pipx

# Проверка версии python
python3 --version

# Проверка версии pip
pip3 --version

# Проверка версии pipx
pipx --version

# Добавить pipx в PATH
pipx ensurepath

# Перезапустить терминал или выполнить:
source ~/.bashrc
```


#### Установка ansible через pipx
```bash
# Установить Ansible
pipx install ansible

# Проверить
ansible --version
```


#### Установка ansible через apt(не самая последняя версия)
```bash
# установка
sudo apt install ansible
```


#### Установка Ansible в виртуальное окружение (venv)
```bash
# Установить модуль venv (если ещё не установлен)
sudo apt install python3-venv

# Создать папку для проекта и перейти в неё
mkdir ~/ansible-project
cd ~/ansible-project

# Создать виртуальное окружение
python3 -m venv ansible-env

# Активировать его
source ansible-env/bin/activate

# Установить Ansible
pip install ansible

# Проверить
ansible --version
```


#### добавить директорию pipx в PATH

```bash
source ~/.bashrc

#или

```
